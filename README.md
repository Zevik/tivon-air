# טבעון מול שאר הארץ

השוואת איכות האוויר בתחנת הניטור של קריית טבעון מול שאר ישראל, 2023–2025. אתר של עמוד אחד, מוכן לפריסה ב-Vercel.

- `site/`: האתר (`index.html` הוא הגרפים; `report`, `appendix`, `main-report` הם המסמכים).
- `tools/build_site.py`: בונה את דפי המסמכים ב-`site/` מקובצי ה-Markdown בשורש. דף הבית (`site/index.html`) נערך ידנית ואינו נדרס, אלא עם `--rebuild-index`.
- `חבילת ראיות - השוואה ארצית/`: דוחות רשמיים, נתונים גולמיים, תוצאות, סקריפטים ו-SHA-256.
- `vercel.json`: מגדיר את `site` כתיקיית הפלט.

הנתונים מהממשק הציבורי של מנ"א, לא מאומתים רשמית. ראו את הדוח לפרטי השיטה וההסתייגויות.
