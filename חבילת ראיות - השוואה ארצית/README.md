הרשימה המלאה עם SHA-256 בסעיף 10 בנספח. שחזור: `python -I fetch_national_year.py 2023` (וכן 2024 ו-2025), `python -I national_analysis.py`, `python -I audit_recompute.py` (בתיקיית `נתונים` של הפרויקט, כאשר הנתונים הגולמיים פרוסים מה-zip).

**הסתייגות:** נתוני ה-API גולמיים ולא עברו בקרת איכות רשמית; אומתו מול דוחות איגוד ערים חיפה, אשדוד (PM2.5) ואשקלון (PM2.5).
